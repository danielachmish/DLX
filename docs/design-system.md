# DLX: מערכת עיצוב "רך ומודרני"

מבוססת על ערכת העיצוב של אלדין, והותאמה ל-DLX. כל מסך בונה **רק** מהרכיבים והטוקנים כאן: בלי מראה חד-פעמי, בלי צבע קשיח בקוד, בלי `style={{}}` לעיצוב (מותר רק למידות דינמיות).

## קבצים

| קובץ | מה יש בו |
|---|---|
| `apps/web/src/styles/dlx.css` | טוקנים (צבע, ריווח, רדיוס, צל), מצב לילה, גודל טקסט, כפתורים, כרטיסים, שדות, לשוניות, חלונות, הודעות, שלד טעינה |
| `apps/web/src/styles/shell.css` | המעטפת: סרגל תחתון (טלפון) · Rail (אייפד) · Sidebar (מחשב), פס עליון |
| `apps/web/src/styles/components.css` | הרכיבים שנוספו ל-DLX: טפסים, טבלת נתונים, תגיות, מקלדת מספרים, קופה, גיליון תשלום, כניסה, הדפסה |
| `apps/web/src/components/ui.tsx` | `Skeleton` `EmptyState` `LoadError` `StatCard` `StatGrid` `Tabs` `ActionBar` `PageHeader` `Money` `Badge` `Field` `Card` `Modal` `Switch` |
| `apps/web/src/components/DataTable.tsx` | טבלה עם מיון. בטלפון היא מוצגת ככרטיסים |
| `apps/web/src/components/NumPad.tsx` | מקלדת מספרים לקופה. עובדת גם עם מקלדת פיזית |
| `apps/web/src/components/Icon.tsx` | אייקונים בקו אחיד + צבע לפי נושא (`TONES`) |
| `apps/web/src/components/hosts.tsx` | `DialogHost` (askConfirm / askText / askChoice), `ToastStack` |

## שלוש תצוגות

| רוחב | ניווט | תוכן |
|---|---|---|
| עד 480px (טלפון) | סרגל תחתון: 4 יעדים לפי תפקיד + "עוד" | עמודה אחת. `ActionBar` צמוד לתחתית. טבלאות מוצגות ככרטיסים |
| 481–1199px (אייפד) | Rail עם אייקון ושם קצר | עד 1440px, ממורכז |
| 1200px+ (מחשב) | Sidebar מלא לפי קבוצות | כנ"ל, עם ריווח רחב יותר |

**קופה:** בטלפון — חיפוש, עגלה, ופס "לתשלום" צמוד מעל הסרגל התחתון. באייפד לאורך — עגלה מתחת לחיפוש. מ-900px (אייפד לרוחב / מחשב) — שני טורים: חיפוש ואריחים מימין, עגלה וסה"כ משמאל, תמיד גלויים (UX-03).

## כללים

- **מצבי מסך:** טוען → `Skeleton` · שגיאה → `LoadError` עם "נסו שוב" · ריק → `EmptyState` עם פעולה. שגיאה אף פעם לא מוצגת כ"אין נתונים".
- **שאלה רק לפני פעולה בלתי הפיכה** (`askConfirm`). פעולה הפיכה — מבצעים מיד ומציגים "ביטול" בהודעה.
- **פעולה ראשית אחת למסך** (`action-btn`). משנית: `secondary`. שלישית: `ghost`. מחיקה: `danger-soft`. `danger` מלא רק בתוך אישור.
- **כסף:** תמיד `Money` / `money()`, עם אגורות. בקופה ובמסמכים אף פעם לא מעגלים לשקל (D-01).
- **תגיות:** ירוק = תקין / הופק · כתום = אזהרה · כחול = אישור מנהל · אדום = חסימה / חריגה · סגול = זיכוי / החזרה.
- **מגע:** כל כפתור ושדה לפחות 44px (`--tap`). בקופה הכפתורים גדולים יותר.
- **נגישות:** `aria-label` לכל כפתור אייקון, `role="alert"` לשגיאות, ניגודיות ≥4.5:1 (טוקן `--muted` כבר מותאם).
- **צבע חדש = טוקן חדש** עם ערך ליום ב-`:root` וערך ללילה בבלוק `html[data-theme="dark"]`.

## הדפסה (D-04)

מסמכים מודפסים מ-HTML שהשרת מפיק (`POST /v1/documents/:id/print` עם `format`: `80mm` / `58mm` / `a4`), דרך `printHtml()`. השרת קובע "מקור" או "העתק". דוחות ומדבקות: HTML פשוט שהמסך בונה ושולח ל-`printHtml()`.
